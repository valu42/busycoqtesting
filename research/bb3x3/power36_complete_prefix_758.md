## Reproduction

Run in this directory:

```sh
python3 power36_complete_prefix_758.py
c++ -O3 -std=c++17 -DPOWER_EXPONENT=35 cross_even_power_758.cpp -o /tmp/cross36
python3 power36_complete_prefix_758.py --worker /tmp/cross36 --jobs 4
```

The first command validates all new receipt endpoints, checks the complete
chain with its earlier receipts and intervening symbolic certificates, and
replays the final full-strip merger. The last command additionally
regenerates all 118 new crossing receipts, comparing every output field.
It retains the earlier blank proof and archived windows as dependencies.

The worker's independent literal-counter audit remains available:

```sh
c++ -O3 -std=c++17 -DPOWER_EXPONENT=35 audit_even_power_758.cpp -o /tmp/audit36
/tmp/audit36
```

The receipt table deliberately remains separate from
`power36_regular_758.tsv` and `blank_bridge_receipts_758.tsv`, preserving the
earlier checkpoints' replay inputs. This is an integer-verified extension;
it does not add a Coq formalization.
